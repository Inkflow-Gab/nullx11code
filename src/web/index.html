Free providers, auto-detected

        
NVIDIA NIM, Groq, Cerebras, OpenRouter :free, Gemini, Mistral, GitHub Models, local Ollama — drop a key in .env and it just appears.

      

      

        
🔎

        
Model auto-detect + icons

        
The agent fetches /models, picks the best free one, and shows every model with its family icon — Llama, Qwen, DeepSeek, Nemotron…

      

      

        
🧩

        
Skills are just folders

        
Point the project at any folder of SKILL.mds. Toggle them per project. They inject into the system prompt only when active.

      

      

        
⌨️

        
/slash commands

        
/model, /skills, /provider, /serve, /doctor… with tab-completion, exactly like opencode.

      

      

        
🛠️

        
Agent tools, human approval

        
Reads, greps and lists files freely — every write and shell command waits for your [y/n/a].

      

      

        
📱

        
Mobile-friendly CLI

        
Line-based ANSI, auto-width, no mouse, no bracketed paste traps. Runs in Termux next to your prompt.
